# CHANGELOG

## Практика / домашняя работа №2 — Стабильная игровая сборка, Фаза 2 и Управление балансом

**Что сделал:**
- Довёл игру до стабильной игровой сессии на 3–5 минут: игра не вылетает, не зависает и не требует перезагрузки страницы.
- Централизовал все параметры баланса и фаз в файле [`src/game/constants.ts`](./src/game/constants.ts): скорость врагов, интервал спавна, плотность толпы и параметры боссов теперь меняются за 2 минуты без поиска чисел в коде.
- Реализовал переключаемую систему Фазы 2:
  - Режим по фрагам (`PHASE2_KILLS_THRESHOLD = 45`, ~50 секунд активного боя);
  - Режим по таймеру (`PHASE2_TIME_THRESHOLD_SEC = 75`, кулдаун 1:15).
- Зафиксировал обе версии в Git отдельными тегами (`phase-v1-time-1m15s` и `phase-v2-kill-count-45`) для демонстрации перехода от таймеров к фрагам.
- Оптимизировал статусную полоску босса: теперь она отображается вверху экрана **только тогда, когда босс виден в поле зрения камеры**, не загромождая интерфейс вдали.
- Добавил аудио-визуальное предупреждение о появлении босса: звуковая кибер-сирена Web Audio API и пульсирующий неоновый баннер на 3.5 секунды.
- Устранил критический тупик (deadlock) поздней игры: при прокачке всех способностей на 100% игра не зависает на пустом модальном окне, а выдаёт моментальный супер-бонус к HP и золоту.
- Доработал меню паузы (<kbd>Esc</kbd>): игровой таймер замирает без накопления скачка дельты кадров `dt`, а фоновое окно видео «Мне скучно» затеняется и ставится на паузу.
- Добавил архитектурную схему Mermaid в `README.md`.

**Три коротких ответа курса:**
1. **Какое изменение было самым дорогим?**
   - Корректная синхронизация игрового времени (`elapsed`) и реального времени браузера при паузе и вызове модальных окон. Потребовалось гарантировать сброс метки `lastTime = performance.now()` при снятии с паузы, чтобы накопленные секунды не приводили к гигантскому скачку дельты кадров `dt` и мгновенному спавну сотен врагов.
2. **Какой участок кода вы упростили?**
   - Управление балансом и параметрами фаз: убрал разрозненные числовые литералы («магические числа») из глубин логики спавна и вынес их в чистый конфигурационный файл [`src/game/constants.ts`](./src/game/constants.ts).
3. **Какая часть системы сейчас самая хрупкая?**
   - Расчёт коллизий и взаимного расталкивания мобов в плотной толпе при достижении максимального лимита (`ENEMY_MAX_CAP = 75` врагов). При дальнейшем увеличении числа объектов квадратичный перебор расстояний может потребовать пространственного хеширования (Spatial Hash Grid).
