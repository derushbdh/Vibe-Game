# Cyber Survivors

Браузерная sci-fi аркада на выживание в жанре Survivor / Bullet Heaven.

**Публичная ссылка на игру:** [https://derushbdh.github.io/Vibe-Game/](https://derushbdh.github.io/Vibe-Game/)

---

## 🎮 Идея и геймплей

> Игрок маневрирует по неоновой арене, уничтожая волны кибер-дронов, собирая кристаллы энергии и прокачивая модули корабля, готовясь к столкновению с боссами.

### Ключевые механики:
- **3 класса дронов:** Страж (авто-бластер), Фантом (орбитальные клинки), Техномант (цепная молния Теслы).
- **8 системных модулей и их эволюции [ОВЕРКЛОК]:** авто-бластер (сдвоенный плазмомет), клинки (грави-диск с ударной волной), молния (буря Теслы с лужами), сверхновая (сингулярная заморозка и огонь), рикошетный чакрам (осколочные диски), турбо-тяга (плазменный след), ядро урона (крит x2.0) и супер-магнит (глобальный импульс).
- **Ангар и мета-прокачка:** банк кредитов `CR` сохраняется в `localStorage` для постоянных улучшений корпуса.
- **Геймплейный цикл на 4 последовательные фазы (~10 минут):**
  1. *Фаза 1 («Разгон», 0:00–3:30)* — спокойный сбор базового билда, волны рядовых дронов (цель: 210 убийств).
  2. *Фаза 2 («Первый рубеж», 3:30–5:00)* — звучит сирена, битва с одиночным боссом. Фаза 3 начинается **только после его гибели** и подбора «Ядра Пробуждения» (+50 CR).
  3. *Фаза 3 («Перегрузка и Ивенты», 5:00–8:00)* — открыта эволюция оружия (Оверклок), спавнятся золотые элитные враги, каждые 45 сек происходят динамические события (цель: 420 убийств).
  4. *Фаза 4 («Апогей и Эвакуация», 8:00–10:00)* — сужение арены смертоносным лазером, бой с двумя боссами подряд и 60 секунд обороны центрального круга эвакуации для Победы (+500 CR).
- **Полноценная пауза (<kbd>Esc</kbd>):** замирание времени без рассинхронизации дельты кадров и затемнение интерфейса.
- **Сбор телеметрии:** история забегов с отображением пройденной фазы, исхода (Победа/Поражение), полученных эволюций и кнопкой скачивания отчёта в JSON.
- **Инструменты тестирования:** `Shift + P` для мгновенного переключения фаз, `K` для проверки экрана поражения.

## 🎮 Как устроены 4 фазы игры (понятным языком)

Вся 10-минутная сессия построена по синусоиде напряжения: **«Волны → Босс → Волны с ивентами → Финальный штурм и Эвакуация»**.

| Фаза | Название | Когда начинается | Что происходит на экране | Главная цель игрока |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Разгон** | С первых секунд забега (0:00) | На арену плавно вылетают дроны (на старте 6 врагов, интервал 1.4с с плавным разгоном до 1.0с). Вверху в HUD горит синяя плашка обратного отсчета: `ФАЗА 1: РАЗГОН (ДО БОССА: 02:30)`. Лимит мобов на экране: 28. | Маневрировать, собирать синие энергокристаллы и прокачать первые 4–5 системных модулей. Продержаться **2:30** (или набрать 220 убийств). |
| **2** | **Первый рубеж** | На отметке **2:30** (или 220 фрагов) | Экран мигает красным, звучит вой тревожной сирены. На арену врывается **один мощный босс** (Кибер-Дредноут, Шторм-Архонт или Сингулярность). Вверху экрана появляется его шкала прочности. Лимит мобов: 38. | Победить босса. **Внимание:** Фаза 3 начнется **строго в момент гибели босса**! Из него выпадает золотое *«Ядро Пробуждения»* (+50 CR), а взрывная волна раскидывает окружение. |
| **3** | **Перегрузка матрицы** | **Сразу после уничтожения босса Фазы 2** | В HUD загорается фиолетовая плашка обратного отсчета: `ФАЗА 3: ЭСКАЛАЦИЯ (ФИНАЛ ЧЕРЕЗ: 03:30)`. **Снимается потолок прокачки:** модули 5-го уровня теперь могут мутировать в супер-оружие **[ОВЕРКЛОК]**. В толпе появляются крупные враги с золотой аурой (10%), а каждые 45 сек происходят микро-ивенты (Рой камикадзе, Конвой +80 CR или Зона ускорения). Лимит мобов: 52. | Прокачать оверклок-модули, перехватывать конвои и продержаться **3:30 (210 сек)** (или набрать 380 фрагов без учета роя камикадзе). |
| **4** | **Апогей и Эвакуация** | Спустя **3:30 в Фазе 3** (или 380 фрагов) | Арену сжимает красный лазерный периметр (за черту заезжать нельзя — сжигает HP). Спавнятся сразу **два финальных босса** подряд. После победы над обоими в центре арены загорается зеленый посадочный круг челнока. Лимит мобов: 70. | Убить обоих боссов, влететь в зеленый круг и **удерживать позицию 60 секунд**. По истечении таймера — **ПОБЕДА (+500 CR)**! |

## ⚙️ Настройки игры и управление балансом

Все балансные параметры и пороги фаз централизованы в файле:
👉 **[`src/game/constants.ts`](./src/game/constants.ts)**

1. **Фаза 1 (Разгон и контроль популяции):** 
   - `ENEMY_SPAWN_INTERVAL = 1400` мс (плавный старт, спавн пачками по 1–2 дрона);
   - `ENEMY_BASE_COUNT = 6` (стартовое число врагов на арене вместо 24);
   - `ENEMY_MAX_CAP_PHASE1 = 28` (динамический лимит толпы в Фазе 1);
   - `PHASE2_TRIGGER_MODE = 'time'` (дефолтный переход по времени на 8–10 мин сессию);
   - `PHASE2_TIME_THRESHOLD_SEC = 150` (босс появляется ровно через 2:30);
   - `PHASE2_KILLS_THRESHOLD = 220` (порог при переключении на режим фрагов).
2. **Фаза 2 (Босс):** 
   - `ENEMY_MAX_CAP_PHASE2 = 38` (лимит мобов во время боя с боссом);
   - 3 вида боссов (*Кибер-Дредноут*, *Шторм-Архонт*, *Сингулярность Бездны*), звуковая сирена, дроп Ядра Пробуждения (+50 CR).
3. **Фаза 3 (Эскалация и Ивенты):** 
   - `ENEMY_MAX_CAP_PHASE3 = 52` (лимит мобов в Фазе 3);
   - `PHASE3_ENEMY_SPEED_SCALE = 1.25` (+25% к скорости мобов);
   - `PHASE3_SPAWN_INTERVAL = 950` мс (умеренно плотные волны);
   - `PHASE3_ELITE_SPAWN_CHANCE = 0.10` (10% шанс элиты);
   - `PHASE3_EVENT_INTERVAL_SEC = 45` с (периодичность случайных событий);
   - `PHASE4_TIME_FROM_PHASE3_SEC = 210` (3:30 выживания внутри Фазы 3);
   - `PHASE4_KILLS_FROM_PHASE3 = 380` (порог при режиме фрагов, рой камикадзе не учитывается).
4. **Фаза 4 (Двойной Босс и Эвакуация):** 
   - `ENEMY_MAX_CAP_PHASE4 = 70` (потолок мобов для финальной битвы);
   - `PHASE4_BOSS_HP_MULT = 1.5` (стойкость финальных боссов);
   - `PHASE4_SECOND_BOSS_DELAY_SEC = 25` с (задержка выхода 2-го босса);
   - `PHASE4_ARENA_BORDER_PADDING = 140` px (отступ лазерной рамки арены);
   - `PHASE4_EXTRACTION_TIME_SEC = 60` с (удержание круга эвакуации);
   - `PHASE4_VICTORY_CR_BONUS = 500` CR (награда за победу).
5. **Боевой баланс и механика «Давка толпы» (Crowd Crush):**
   - `ENEMY_BASE_CONTACT_DAMAGE = 18` (базовый контактный урон);
   - `PLAYER_IFRAMES_DURATION_SEC = 0.22` (окно неуязвимости 0.22 сек вместо 0.58 сек);
   - `CROWD_CRUSH_EXTRA_DAMAGE_MULT = 0.35` (+35% к урону за каждого дополнительного моба в контакте);
   - `ENEMY_HP_PHASE_SCALE = [1.0, 1.5, 2.4, 3.2]` (+15% HP мобов за минуту выживания);
   - Базовое HP классов: Страж = 110, Фантом = 80, Техномант = 90;
   - Титановая броня в Ангаре: +10 HP за уровень (макс +50 HP);
   - Оверклок Супер-магнита: +8 HP за импульс.

## 🏷 Контроль версий и теги

В репозитории зафиксированы ключевые этапы исследования механик:

- **`phase-v1-time-1m15s`** — Фаза 2 (босс) активируется строго по **таймеру 1:15** (75 сек):
  ```bash
  git checkout phase-v1-time-1m15s
  ```
- **`phase-v2-kill-count-45`** — Фаза 2 (босс) активируется по **45 фрагам** (~50 сек):
  ```bash
  git checkout phase-v2-kill-count-45
  ```
- **`game-constants-config`** (`main`) — актуальная версия с выносом всех настроек в [`src/game/constants.ts`](./src/game/constants.ts):
  ```bash
  git checkout main
  ```

## 🕹 Управление

- **Клавиатура:** `W`, `A`, `S`, `D` или стрелочки.
- **Мышь / Тач:** зажмите ЛКМ или палец на экране и ведите (виртуальный экранный джойстик).
- **Пауза:** клавиша <kbd>Esc</kbd> или кнопка «⏸ Пауза» в верхнем HUD.
- **Стрельба:** автоматическая по ближайшим целям.
